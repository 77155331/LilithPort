# LilithPort
基于LilithPort1.08汉化，增加了启动参数，增加了LAN/N2N扫描网路服务端
参数	格式	说明
-s	-s [端口号]	启动服务端（开房主机），端口可选；不填端口默认 7500
示例：LilithPort.exe -s 7500
-c	-c <ip:port>	作为客户端连接到指定服务器，必填 IP + 端口
示例：LilithPort.exe -c 192.168.1.10:7500
-n	-n <昵称>	设置玩家昵称（房主 / 客户端都可用）
示例：LilithPort.exe -s -n "房主小明"
-room	-room <服务器名>	设置服务器名称，局域网搜索列表会展示这个服务器名
示例：-room "2DFM对战房"
-g	-g <exe路径>	指定游戏 exe（2D Fighter Maker 2002 的游戏主程序）路径
示例：-g "D:\game\kgt.exe"
-a	-a	就绪后自动启动游戏，不需要手动点启动
-f	-f	离线自由对战模式（单机本地模式，不联网）
-stage	-stage <数字>	开局自动选择关卡 / 场景编号，和你之前的 2DFM 持久存档配套
-round	-round <数字>	设置对局回合数
-timer	-timer <数字>	设置对战倒计时时长
-h	-h	打印帮助文本，展示全部参数后直接退出程序
-motd	-motd <公告文本>	✅ 我们新增：服务端开房时设置房间公告（MOTD，玩家进入看到的长公告）
示例：-motd "禁止乱抢角色，掉线请重连"
-sign	-sign <签名文本>	✅ 我们新增：服务端开房时设置房主签名（备注，在列表不展示，在玩家列表评论栏显示）
示例：-sign "只打熟练玩家"
