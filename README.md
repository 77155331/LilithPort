# LilithPort
基于LilithPort1.08汉化，增加了启动参数，增加了LAN/N2N扫描网路服务端


-s
-s [端口号]	启动服务端（开房主机），端口可选；不填端口默认 7500
示例：LilithPort.exe -s 7500

-c
-c <ip:port>	作为客户端连接到指定服务器，必填 IP + 端口
示例：LilithPort.exe -c 192.168.1.10:7500

-n
-n <昵称>	设置玩家昵称（房主 / 客户端都可用）
示例：LilithPort.exe -s -n "房主小明"

-sign
-sign <签名文本>	服务端开房时设置房主签名（备注，在列表不展示，在玩家列表评论栏显示）
示例：-sign "只打熟练玩家"

-room
-room <服务器名>	设置服务器名称，局域网搜索列表会展示这个服务器名
示例：-room "2DFM对战房"

-motd
-motd <公告文本>	服务端开房时设置房间公告（MOTD，玩家进入看到的长公告）
公告文本中“_”为换行替代符号
示例：-motd "禁止乱抢角色_掉线请重连"

-g
-g <exe路径>	指定游戏 exe（2D Fighter Maker 2002 的游戏主程序）路径
示例：-g "D:\game\kgt.exe"

-a
-a	就绪后自动启动游戏，不需要手动点启动

-f
-f	离线自由对战模式（单机本地模式，不联网）

-stage
-stage <数字>	开局自动选择关卡 / 场景编号

-round
-round <数字>	设置对局回合数

-timer
-timer <数字>	设置对战倒计时时长

-p
-p <数字>	监听端口

-auto
启动时先花 **1.5 秒**在局域网 /n2n 里广播找服，规则和界面上的「搜索服务器」完全一致（7510/7511 两个端口都探测、每块网卡的子网广播都发、**本机的服务器不算**），然后：

- **搜到服** → 自动以 `CT_HOST`（主机端）加入，地址直接填好，不弹启动对话框；
- **没搜到** → 自己开服（`CT_SERVER`），也不弹对话框。

LilithPort.exe -auto -room "我的服务器" -n "玩家A" -sign "签名" -motd "欢迎加入_掉线请重连"
第一个启动的人自动成为房主，后面启动的人自动以主机端进同一个房。想连上就立刻开局，再加 `-a -g "game.exe"`：
LilithPort.exe -auto -a -g "game.exe" -room "我的服务器" -n "玩家A"
别名：`--auto` / `-find` / `-as`。


-h
-h	打印帮助文本，展示全部参数后直接退出程序

LilithPort.exe -s 7500 -n "房主" -room "我的服务器" -motd "欢迎来房，掉线重连" -sign "老手房" -g "game.exe" -a -round 3 -timer 99

LilithPort.exe -c 192.168.1.10:7500 -n "玩家A" -sign "新手房" -g "game.exe" -a

补充说明：

1. `-s` 和 `-c` **不能同时使用**，要么当主机，要么当客户端；
2. 带空格的字符串（昵称、房间名、公告、签名、路径）**一定要加英文双引号**；
3. `-motd`、`-sign` 只有**启动服务端 (-s)**的时候才生效，客户端带这两个参数无效；
4. 局域网搜索列表展示顺序：`房间名` → `IP:端口 人数` → `房主昵称`，**不再展示 sign 签名**。
